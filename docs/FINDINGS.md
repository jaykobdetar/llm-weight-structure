# Findings and boundaries

This is a faithful summary of saved results, not a new model run. Distinguish scientific failures of a frozen gate, detector failures, technical stops and unrun work. Prompt observations, local MLP calls, block evaluations and full-model forwards are different units.

## Receiver comparison

The native-port selector and a direct-embedding comparator were locked to the same 261-head universe and evaluated on the same fixed panel. The native selector nominated SmolLM2 L18H6; the static comparator nominated L29H1. The confirmation contained eight paired clusters, preceded by 16 discovery and four identity forwards. The full ledger reports 132 calls: 16 discovery, four identity, 16 confirmation baselines and 96 edits. The control was a single fixed-seed, norm-matched synthetic additive write in the chosen output span for each prompt; it does not represent every semantic alternative.

The median paired contrast is not the difference of the two displayed medians. The independent saved-record audit checked scalar reductions, pins and the recorded ledger; it did not reconstruct unsaved logits, hidden states, singular vectors or control directions. The selected native score included routing and gain awareness as well as contextualization, so the comparison does not isolate those elements. No key construction, source-predecessor mechanism or complete-head algorithm was established. The panel is already consumed.

## Additional later records

**Pythia C2 input/output interface.** An independent saved-row audit reports 26 literal ASCII pairs, one true pairing and 19 deterministic cyclic mismatches per checkpoint. The predeclared compatibility score was 1.9787913502 at final and 1.9786423150 at initialization, versus a maximum of 0.10; both were `INCOMPATIBLE`. The controls did not establish the frozen output-separation margin. This is a weight-only interface result, not model behavior or proof against all structure. No model forward was run; two whole-file integrity passes per checkpoint did read all raw checkpoint bytes. The result and provenance are in the [independent audit](../evidence/c2-independent-audit.txt); the full native-weight evidence is not included.

**Trained Pythia MLP pilot.** The worker completed eight fixed-panel states and recorded 0/8 full-program passes, but the overall guardian reports `live-child-memory-unavailable`. The independently saved-result audit supports the subordinate values conditionally; it does not waive the guardian failure or establish its cause. The experiment remains a technical hold, not a clean scientific negative. [Monitoring subset](../evidence/trained-mlp-monitoring-subset.json).

**Smol Stage A.** A separate fixed, correlated eight-case development panel passed 8/8: four technical-parity and 24 capability forwards, 17 reported aggregate parity diagnostics, and 24 independently recomputed FP32 scalar margins. The saved audit verified 116 array hashes/shapes/finiteness; raw parity vectors, native arithmetic execution and checkpoint provenance were not independently reconstructed by that audit. Full-model loading and ordinary MLP execution occurred. There were zero selector or Stage B local-MLP calls. The result is development-only, not confirmation or evidence of a bilinear group. [Independent receipt](../evidence/stage-a-audit.json).

**Generated selector v8.** A fixed absolute FP32-versus-FP64 error limit was infeasible for an observed reference: the nearest FP32 value was about `3.32456e-6` away, exceeding `2e-6`. This is a failed generated qualifier with an invalid comparator at that coordinate, not a native model result. The [saved feasibility note](../evidence/selector-v8-comparator.json) retains the actual failure.
