# Methods, limitations and future questions

## Interpretation safeguards

- Distinguish discovered computation from a detector's power. A selector that misses planted structure fails its own qualification; it says nothing by itself about native model structure.
- Separate removal from causal specificity. A damaging ablation can disrupt information in many ways. A successful replacement or patch can use dormant pathways or artificial off-manifold states; it is not automatically a faithful native mechanism.
- Match attention normalization, projection, head/KV grouping, bias and residual ordering to the exact model and intervention point. A native identity test must pass at the relevant output, with retained error bounds, before interpreting a swap. The Pythia replacement path did not pass its native identity gate.
- Treat the document or paired cluster as the unit of inference. A few selected labels, repeated contexts, and one matched control per prompt do not support population claims; confidence intervals do not remove selection bias.
- Preserve all failed gates and unopened stages. Do not call unseen an unrun panel if it was consumed elsewhere, and do not turn adaptive selection into preregistered confirmation. Do not pool block calls and full forwards.
- Reconstruct precision comparisons from actual bit patterns and the operation tree. Fixed absolute tolerances can be infeasible at large FP32 magnitudes. Finite computed-output bounds are not exact-real MLP proofs or guarantees about hidden kernel intermediates.

## Existing resource boundaries

The historical small-model native guard commonly used one CPU, 7 GiB host admission / sampled stop below 6 GiB, a 3 GiB worker limit and 120 seconds for a specific pilot. Static work had separate 512 MiB budgets. Later Smol Stage A had a separately approved worker 4 GiB virtual address-space limit and 2.5 GiB sampled/terminal RSS, support-process address-space allowances, 1150/20/5/3 CPU seconds and 1700/1750/1800-second wall ceilings. Virtual address space is not RSS, sampled memory is not continuous enforcement, support charges are not measured group RSS, and blocked I/O or scheduler gaps remain. None of these historical values authorizes a new run.

## Falsifiable follow-ups for design only

1. **Receiver mechanism.** Freeze a new independent panel and predict when the L18H6 copied source will change based on query/key and source binding. Compare native routing, identity, same-site norm-matched controls and a behavioral failure condition. Go only after the capability gate, intervention identity and preregistered control outcomes hold; failure limits the proposed key mechanism, not induction generally.
2. **Whole-vector nonlinear interaction.** If a new independently qualified instrument and fresh data are authorized, preselect one port and original-neuron group, then test the full-vector mixed difference `F(x+A+B)-F(x+A)-F(x+B)+F(x)` against a fixed derivative prediction. Distinguish live from fixed RMSNorm and test concentration, coherence and half-dose behavior. Report a failed full-vector or normalization gate as such; do not fit after seeing outcomes. The earlier Stage B design was not executed and cannot be presented as a result.
3. **Distinguish detector failure from absence.** Before any broader native screen, use fixed generated controls representing positive, shared-up, normalization-only and competitor alternatives with prespecified expected failures. A detector that misses the planted case or an unresolved numerical comparator blocks the native claim; a fresh synthetic success only supports that instrument in its tested domain.
4. **Transfer only after instrument identity.** A Pythia transfer test requires a separately qualified native identity and nonzero edit path; source-free shape checks or unchanged argmax alone are insufficient. If identity fails, stop without interpreting causal absence.

These are research proposals, not permissions to execute. Any new experiment needs an independent preregistration of candidate selection, exact inputs and controls, effect size, stopping rules, numerical criteria, evidence retention and resources. Avoid treating a recovered summary or this documentation as an untouched confirmation panel.
